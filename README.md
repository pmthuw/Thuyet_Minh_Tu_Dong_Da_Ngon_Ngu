# Cong_Nghe_Phan_Mem
// Bán vé xem phim//
1. Users ( Người mua - khách hàng, nhân viên, admin quản lý)
2. Phim ( Tên, suất chiếu, thể loại, thời lượng, dạo diễn, trạng thái: đang/sắp)
3. Rạp ( Rạp chiếu, phòng chiếu, danh sách ghế)
4. Chi tiết ghế ( số ghé, dãy ghế, hạng ghế: thường, đôi, vip,...)
5. Đơn đặt vé ( mã vé, ngày tháng đặt, số tiền, khung giờ, tên phim, giờ chiếu, chi nhánh rạp,...)
---------------------
Ấn vào poster -> Mua vé -> Chọn suất chiếu, thời gian -> Chọn ghế ( đã đặt, ghế thường, ghế vip, ghế bạn chọn) -> Hiện thị số tiền -> Combo bắp nước -> Thông tin đặt vé -> Xác nhận đặt vé -> Trả tiền
---------------------
